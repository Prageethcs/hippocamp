# Code of Conduct

Hippocamp adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. In short: be respectful, assume good faith, and help keep this a project people want to contribute to.

The full text — including the standards we hold ourselves to, examples of unacceptable behavior, and the enforcement guidelines maintainers follow — is at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Scope

This Code of Conduct applies in all project spaces — the GitHub repository (issues, pull requests, discussions, commit messages, code review) and any other venue where someone is representing Hippocamp.

## Reporting

If you experience or witness behavior that violates this Code of Conduct, please report it to the maintainer at **prageeth.cs@gmail.com**. Reports are handled confidentially.

For security vulnerabilities, use the process in [SECURITY.md](SECURITY.md) instead — not this address.

## Enforcement

The maintainer is responsible for clarifying and enforcing this Code of Conduct, and will follow the [Contributor Covenant Enforcement Guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) when deciding on consequences. Actions can range from a private warning up to a permanent ban from project spaces, depending on the severity and pattern of the behavior.
